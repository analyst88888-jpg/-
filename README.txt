SYSTEM PWA
==========
ไฟล์ชุดนี้เตรียม SYSTEM.html ให้ติดตั้งเป็นเว็บแอป (PWA) บน Android ได้

วิธีเผยแพร่:
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ไปไว้ใน repository หรือโฮสต์เว็บเดียวกัน
3. เปิดใช้งาน GitHub Pages (หรือโฮสต์ HTTPS อื่น)
4. เปิด URL ของเว็บผ่าน Chrome บน Android
5. แตะเมนู ⋮ > ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก

สำคัญ:
- ต้องอัปโหลดทั้ง index.html, manifest.webmanifest, sw.js และโฟลเดอร์ icons
- ต้องเปิดผ่าน HTTPS (GitHub Pages รองรับ) ไม่ใช่เปิดไฟล์ HTML จากเครื่องโดยตรง
- ข้อมูลเกมเดิมเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น การติดตั้งแอปไม่ได้ย้ายข้อมูลข้ามเบราว์เซอร์ให้อัตโนมัติ
- Service worker ช่วยแคชหน้าแอปสำหรับการเปิดครั้งถัดไปเมื่อเคยโหลดออนไลน์แล้ว
